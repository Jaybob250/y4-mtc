# y4-🎮 MTC ARCADE: BUTTONVERSE

One arcade. Two worlds. Endless buttons.

MTC ARCADE: BUTTONVERSE is a browser-based arcade game combining fast-paced multiplication challenges, MTC practice tests, bonus mini-games and a secret alternate game mode.

🌟 Features

🧮 Maths Arcade

* Hit the Button: Fast-paced multiplication challenges.
* MTC Test: 25-question multiplication practice.
* Star Tap: Bonus mini-game between maths rounds.
* Times tables from 2× to 12×.
* Score and streak tracking.
* Adjustable session settings.

🧸 Foam-Dart Defence

A secret alternate arcade mode featuring:

* Original knitted doll characters.
* Different character appearances and abilities.
* Foam-dart blasters.
* Garden defence gameplay.
* Waves and unlockable characters.

📚 Doll Index

* Character collection.
* Character profiles.
* Special abilities.
* Rarity information.
* Discovery progress.

⚙️ Developer Options

* Hidden Developer Options.
* Admin Panel.
* Reversible Remove Maths switch.
* Restore Maths functionality.
* Eye disguise button to make the alternate mode look like MTC mode.

💾 Saving Progress

Game progress is saved using browser local storage.

Important: Saves are stored locally on the browser and device being used. They do not automatically transfer between devices or browsers.

Clearing browser data may erase saved progress.

🚀 How to Play

1. Open the website.
2. Choose Hit the Button or MTC Test.
3. Answer multiplication questions.
4. Earn stars and build streaks.
5. Explore the bonus games.

The alternate game mode can be accessed through the hidden Developer Options and Admin Panel.

🛠️ Technology

* HTML
* CSS
* JavaScript
* Browser Local Storage

No installation required. Play directly in a supported web browser.
